# Mémoire de l'entreprise Astoria Mods

L'équipe des Bureaux d'Astoria (`monde/index.html`) travaille seule chaque jour. Elle lit et met à jour ces fichiers :

- `backlog.md` : idées, projets et tâches en cours, avec le collègue responsable.
- `decisions.md` : décisions prises par Karim (le fondateur). Elles s'imposent à toute l'équipe.
- `journal/AAAA-MM-JJ.md` : compte rendu de chaque journée (réunion, travail fait, décisions à prendre).
- `../livrables/<collègue>/` : les livrables produits (analyses, scripts, plans…).
