# Actions à appliquer dans le centre vendeur

L'équipe (session cloud) prépare ici, chaque jour, des fichiers d'actions **validées par Karim**.
Karim les fait appliquer par **Claude dans Chrome**, sur son Mac, en lui écrivant :
« Applique le fichier entreprise/a-appliquer/<fichier>.md du dépôt astoria-mandat-ia. »

Règles pour Claude dans Chrome :
- n'appliquer **que** ce qui est écrit dans le fichier, champ par champ, puis faire une capture du résultat ;
- **jamais** : paiement, publicité payante, expédition ou annulation de commande, suppression de produit, sans un « oui » explicite de Karim dans la conversation ;
- s'arrêter et demander à Karim en cas de doute ou de message d'erreur ;
- à la fin, résumer ce qui a été fait. Karim recolle le résumé dans la session de l'équipe.
